## Baseline capabilities

Audistill 0.4.0 is the first release line with the core local-first workflow in place.

### Local-first Episode Library

- Create Episodes from local audio files, YouTube links, RSS feed items, and direct media URLs.
- Keep completed Episodes self-contained with Transcript, Tabs, Source provenance, and Chat history stored locally.
- Organize the Library with Inbox, folders, nested folders, Starred Episodes, search, sorting, drag-and-drop, and bulk actions.

### On-device Transcription

- Download and manage the local Transcription Model.
- Run Transcription on-device, with progress states for queued, downloading, transcribing, generating, complete, cancelled, and error Episodes.
- Retry failed or cancelled work without losing existing Library data.

### Recipes, Tabs, and Chat

- Use built-in Recipes to generate Brief, Detailed, and Full Tabs from Transcripts.
- Create, duplicate, edit, and delete custom Recipes, including per-Recipe Model overrides.
- Pick a Pipeline Recipe that runs during Ingest.
- Edit, regenerate, copy, and export Tab content with rich Markdown rendering, including tables, highlights, task lists, and Mermaid diagrams.
- Use per-Episode Chat with Library-aware tools and Tab-writing actions.

### BYOK Models and licensing

- Connect your own OpenRouter API key and choose the Model used for Recipe execution and Chat.
- Use the 14-day Trial in official builds, then activate a one-time License through Polar.
- Keep existing Episodes viewable even when creation features are gated.

### macOS app experience

- Signed macOS builds support automatic update checks, downloaded update banners, restart-to-install, and update dismissal.
- The app restores window state and open workspace tabs across restarts.
